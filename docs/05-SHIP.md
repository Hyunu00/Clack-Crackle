# 05 — 출시 체크리스트

## 0. 지금 시작할 것 (게임 없어도 됨)

행정이 개발보다 오래 걸릴 수 있다. 대기 시간을 개발 기간과 겹치게 하는 게 목적.

- [ ] 구매 이력 있는 기존 스팀 계정으로 Steamworks 가입
      (신규 계정은 일부 기능이 잠겨 진행이 막힌다)
- [ ] 이용약관 서명
- [ ] **세금 정보(W-8BEN) 제출** — 검증에 최대 30일. 가장 자주 일정을 망침
- [ ] 은행 계좌 등록
- [ ] 사업자등록 여부 결정

## 1. 스팀 절차

```
가입 → 세금 검증(2~7일, 최대 30일) → $100 결제 → 30일 의무 대기
     → 스토어 페이지 검토(3~5영업일) → 출시 예정 페이지 공개(최소 14일)
     → 빌드 검토(3~5영업일) → 출시
```

- $100 은 제품당 1회, 환불 불가. 조정 총수익 $1,000 달성 후 회수
- 30일 대기와 14일 출시 예정 기간은 겹칠 수 있다
- 현실적 최소 5~6주. 첫 출시면 8~10주로 잡을 것

## 2. 빌드 (Electron 붙일 때)

- [ ] `electron-builder` 타겟 `dir`. **`nsis` 설치 파일을 올리면 안 된다**
- [ ] `asarUnpack: ["**/*.node"]` — steamworks.js 네이티브 모듈
- [ ] Electron 버전 고정 (`^` 제거). 메이저 업그레이드 시 ABI 가 깨진다
- [ ] `backgroundThrottling: false` + `electronEnableSteamOverlay()`
- [ ] **`steam_appid.txt` 를 출시 빌드에서 제외.** 밸브 리뷰에서 잡힌다
- [ ] `app_build.vdf` 의 `preview` = `0`
- [ ] `setlive` 는 비워둘 것
- [ ] 깨끗한 PC 에서 실행 테스트

## 3. 스토어 페이지

- [ ] 캡슐 6종 (`docs/03-ART.md` 규격)
- [ ] 스크린샷 5장 이상
- [ ] 트레일러 — **첫 5초 안에 왁뿌볼이 부서져야 한다.** 로고부터 보여주지 말 것
- [ ] 짧은 설명 / 긴 설명 (GIF 섞을 것. 이 게임은 움직임이 전부)
- [ ] 태그 — 아래 3층으로. 순서가 노출에 쓰인다
      - 장르: `Incremental` `Idler` `Point & Click` `Simulation` `Casual` `Indie`
      - 감각/외형: `Relaxing` `Colorful` `Cute` `2D` `Collectathon`
      (`Pixel Graphics` 는 2026-09 캐주얼 아트 전환으로 제외 —
      `docs/06-DECISIONS.md` "아트 스타일 — 픽셀 → 캐주얼")
      - 유행 유입: `ASMR` + `wax cracking` 계열 (짧은 설명에도)
      → **유행 태그는 언제든 순서를 내리면 된다. 리스크 0.**
      참고: 레퍼런스작 `Click the Button`(LoopCap, 2026-08-26)은
      `Clicker` 태그를 쓰지 않고 `Idler` + `Incremental` + `Point & Click` 로 간다.
      룰렛 때문에 `Gambling` 태그가 붙을 수 있다 — 붙일지 말지 검토할 것
- [ ] 가격 4,000원 + 지역별 가격 (스팀 권장값)
- [ ] 시스템 요구사항

## 4. 게임 내 필수

- [ ] 설정 — 볼륨(마스터/효과음/BGM), 창모드/전체화면, 언어,
      **균열 단계 수(3/4/5, 기본 4)** — 감각 설정이라 밸런스에 영향 없음
- [ ] **룰렛 확률 표시 화면** (법적 의무는 아니지만 반드시)
- [ ] 세이브 + 손상된 세이브에서 죽지 않는지 테스트
- [ ] **처음부터 다시하기** (세이브 슬롯이 없으므로 필수)
- [ ] 스팀 클라우드 (Auto-Cloud)
- [ ] 업적 26개
- [ ] 자동화 토글 UI (3단계 각각 ON/OFF)
- [ ] 종료 기능
- [ ] 크레딧 — 폰트/음원/라이브러리 라이선스
- [ ] 버전 표시

## 5. 현지화

**전문은 `docs/10-I18N.md`.** 여기는 출시 체크리스트만 둔다.

- [ ] 문자열을 `src/i18n/` 로 분리 (1일차)
- [ ] **T1 9개 언어** — 한 · 영 · 중간체 · 러시아 · 일 · 스페인 · 포르투갈(브라질) · 독일 · 프랑스
- [ ] 스토어 페이지 현지화 (T1 전부). **게임 내 번역보다 ROI 가 높다**
- [ ] 스팀 "지원 언어" 표 — 음성이 없으므로 인터페이스만 체크
- [ ] **업적 26개의 이름·설명을 스팀 쪽에도 현지화.** 게임 안 JSON 과 별개다
- [ ] 한국어 스토어에 현지화 제목 `나만 없어 왁뿌볼` 지정
- [ ] **한국어 캡슐 이미지 별도 제작** — 제목이 다르다
- [ ] 폰트 글리프 커버리지 확인 — 확장 라틴(ß ł ı ñ ç), 키릴, CJK.
      캐주얼 아트 전환 후 벡터 폰트를 쓰므로 픽셀 폰트 시절보다 선택지가
      넓다. 그래도 한/중/일이 한 폰트로 안 될 수 있으니 프로필별 폴백
      구조는 그대로 확인할 것 (`docs/10-I18N.md` 폰트 매트릭스)
- [ ] `npm run shot` 을 **독일어로** 한 번 — 영어 대비 1.3배라 UI 가 가장 잘 터진다

## 6. 한국 관련

- [ ] 게임물 등급분류 — 국내 유통 게임은 원칙적으로 대상.
      게임위 직접 신청 또는 자체등급분류사업자 경로.
      스팀 출시 한국 인디에게 실무와 법 조문 사이 회색지대가 있으니
      수익 발생 시점에 정리할 것
- [ ] 사업자등록 / 종합소득세
- [ ] 확률형 아이템 표시 의무 — **IAP 없으므로 대상 아님**

법률·세무는 전문가 확인이 필요하다. 이건 체크리스트일 뿐이다.

## 7. 마케팅

2025년 스팀 출시작 약 21,500개 중 절반 가까이가 100장 미만을 팔았다.
차이는 대부분 출시 몇 달 전에 갈린다.

- [ ] **출시 예정 페이지를 최대한 일찍 공개.** 찜 목록이 출시일 노출을 결정.
      목표 **2026년 10월**. 스크린샷 5장만 있으면 되고 리스크가 0이다
- [ ] **데모 + 넥스트 페스트** — 4,000원 클리커에는 사실상 필수.
      → **2027년 2월 회차 확정.** 아래 요건과 마감을 지킬 것
- [ ] 숏폼 — 부서지는 장면 15초면 끝난다. 궁합이 극도로 좋다
- [ ] r/incremental_games — 이 장르는 커뮤니티가 명확하다
- [ ] 개발 로그 (X, 디스코드)

### 넥스트 페스트 — 요건과 마감

**게임당 평생 1회다.** 덜 익은 데모로 태우면 회수할 방법이 없고,
이 게임 최대의 노출 기회를 빈손으로 쓰게 된다.

참가 요건 (전부 충족해야 함):

- 스토어 페이지가 **등록 시점에 이미 공개**되어 있을 것
- 축제 시작 시점에 **공개적으로 플레이 가능한 데모**가 있을 것
- 미출시작일 것. 참가작은 **회차 종료 후**에 출시해야 한다
- 이전 넥스트 페스트에 참가한 적이 없을 것
- 기존 게임의 프롤로그/챕터1이 아닐 것

회차 일정 (실측):

| 회차 | 개최 | 등록 마감 |
|---|---|---|
| 2026년 2월 | 2/23 ~ 3/2 | 1/5 |
| 2026년 6월 | 6/15 ~ 6/22 | 5월 초 |
| 2026년 10월 | 10/19 ~ 10/26 | **8/31** — 대기자 없음, 예외 없음 |
| **2027년 2월** | 2월 하순 (예상) | **2027년 1월 초 (예상)** |

**2027년 2월 회차의 정확한 날짜는 Steamworks 대시보드에서 확인할 것.**
위 2027년 행은 2026년 2월 회차에서 유추한 값이다.

역산하면 이렇게 된다:

```
2026년 10월      출시 예정 페이지 공개          ← 스크린샷 5장
2026년 12월      데모 빌드 완성 + 내부 테스트
2027년 1월 초    넥스트 페스트 등록 마감        ← 페이지가 공개 상태여야 함
2027년 2월 하순  넥스트 페스트. 데모 공개
2027년 3월 이후  출시                          ← 회차 종료 후여야 함
```
