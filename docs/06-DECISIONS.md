# 06 — 결정 로그

되돌리기 어려운 결정만 기록한다.

---

## 웹 스택 (TypeScript + PixiJS + Electron)

**결정:** Unity/Godot 대신 TS + PixiJS. 스팀 배포는 Electron 포장.
**이유:** AI 에이전트 주도 개발이 전제. Unity/Godot 은 씬 조립이 에디터 GUI
안에 있어 에이전트가 절반만 일한다. 웹 스택은 전부 텍스트이고 브라우저 +
Playwright 로 에이전트가 스스로 화면을 검증한다.
**포기한 것:** Steam Deck 검증 사실상 불가. 빌드 200MB+.
**되돌리는 비용:** 높음 (재작성)

## core / render 분리 (순수 함수 엔진)

**결정:** `src/core/` 는 pixi 를 import 하지 않는다.
**이유:** 밸런스 시뮬레이션을 화면 없이 돌리기 위해서.
**되돌리는 비용:** 중간. 되돌리면 개발 방식이 무너진다.

## 인앱결제 미도입

**결정:** IAP 없음. 4,000원 매절.
**이유:** 확률형 아이템 표시 의무는 유상 구매 아이템이 대상. IAP 가 없으면
대상이 아니고 룰렛을 자유롭게 설계할 수 있다.
**되돌리는 비용:** 높음 (표시 의무, 등급 재분류, 결제 연동이 따라옴)

## 왁뿌볼 종류 × 등급 직교

**결정:** 종류(스프라이트 + 기초가치) × 등급(틴트 + 이펙트 + 배율) 런타임 조합.
균열은 공용 오버레이 5장.
**이유:** 50×5 = 250조합을 50 + 5 + 5 = 60장으로 만든다. 종류 추가가 가장 싼
업데이트 카드가 된다 (스프라이트 1장 = 5조합).
**되돌리는 비용:** 중간. 조합을 스프라이트로 구우면 확장이 막힌다.

## 종류를 룰렛으로 해금 + 중복은 레벨업

**결정:** 시작 시 ★1 중 1종만 보유. 룰렛 종류 슬롯에서 해금.
이미 보유한 종류가 나오면 레벨업(기초가치 ×1.2, 상한 없음).
해금은 희귀도 추첨, 레벨업은 균등 랜덤.
**이유:** 유한 해금만 있으면 50번 뽑고 그 슬롯이 죽은 칸이 된다.
레벨업이 있으면 슬롯이 영원히 의미를 갖고, 골드의 무한 소비처가 된다.
해금이 미보유 중에서만 뽑히므로 쿠폰 수집 문제도 없다(정확히 50회).
**되돌리는 비용:** 중간

## 룰렛 비용 지수 상승 + 환생 리셋

**결정:** `비용 = 100 × 1.04^(이번 판 횟수)`, 환생 시 리셋.
**이유:** 단일 슬롯 룰렛은 가격이 고정이면 골드 수입이 커질수록 무한 연타가
되고 골드가 무의미해진다. 이 곡선이 환생 타이밍을 시스템에서 만들어낸다.
**되돌리는 비용:** 낮지만 빼면 경제가 붕괴한다.

## 키캡이 왁뿌볼을 생산

**결정:** 키캡 N타마다 왁뿌볼 1개 생산. 등급별로 주기가 다름.
**이유:** 초안에서는 키캡이 골드만 줬는데 왁뿌볼 수입이 훨씬 커서 30분이면
키캡을 안 만지게 된다. 화면 주인공이 무의미해지는 문제.
**되돌리는 비용:** 중간

## 환생재화 = √(누적 골드) 스케일

**결정:** 고정값(등급 1.0~2.0)이 아니라 제곱근 스케일.
**이유:** 고정값이면 100회차 환생이 1회차와 같은 재화를 벌어온다.
스킬트리 상위 노드에 가격을 붙일 수 없고 "환생할수록 강해진다"가 안 나온다.
제곱근은 인크리멘탈 프레스티지 표준 — 골드 100배면 재화 10배.
**되돌리는 비용:** 낮음. 하지만 안 하면 장기 플레이가 성립하지 않는다.

## 자동화 3단계 전부 도입

**결정:** 자동 키캡 → 자동 파괴(골드 60%) → 자동 룰렛.
**이유:** 인크리멘탈에서 손가락 속도가 게임 상한이 되면 안 된다.
**주의:** 자동 파괴의 60% 페널티와 "처음 보는 조합은 수동" 규칙이
ASMR 을 지키는 유일한 장치다. 약화시키지 말 것.
**되돌리는 비용:** 중간

## 균열 5단계 + 꾹 누르기는 연속 진행 (2026-08)

**결정:** 균열은 **5단계**. 오버레이 5장(공용) / 사운드 `ball_crack_1`~`5`.
진행률 20% 간격이고, **클릭 수가 아니라 진행률로 계산한다.**
꾹 누르기는 누르고 있는 동안 진행률이 연속으로 올라 5단계를 이어서 지나간다.

**이유:** 문서마다 4(`04-AUDIO`)와 5(`03-ART`, `CLAUDE.md` 절대 규칙 5)로
갈려 있었다. 5로 통일하면 사운드 목록에 한 줄(음원 3개)만 추가하면 되고,
4로 내리면 **절대 규칙을 고쳐야 한다.** 추가 비용이 PNG 0장 + 음원 3개라
사실상 없는데, "부수는 순간의 손맛"이 최우선 판단 기준이므로 단계가
촘촘한 쪽이 맞다.

진행률 기준으로 못박은 이유: 필요 클릭이 등급마다 20~30 으로 다르고
스킬트리 "부수기 효율"이 12 까지 줄인다. 클릭 수로 단계를 나누면
스킬을 찍는 순간 균열 연출이 깨진다.

**포기한 것:** 없음. 음원 3개.
**되돌리는 비용:** 낮음. 단계 수는 `content/` 상수 하나다.
단, 음원을 녹음한 뒤에 바꾸면 재녹음이다.

## 2차 환생 여지 (세이브 3층 구조)

**결정:** 2차 환생을 구현하지 않되 세이브를 3층으로 나눈다.
1차 리셋 / 2차 리셋 대상 / 영구.
**이유:** 나중에 넣을 때 세이브 마이그레이션이 필요 없어진다.
**되돌리는 비용:** 지금 안 하면 나중에 높아진다.

## 오프라인 진행 없음

**결정:** 방치 수입은 게임이 켜져 있을 때만.
**되돌리는 비용:** 낮음 (`applyOffline` 이 이미 있어 켜기만 하면 됨)

**이유:** 손맛 장치지만 v1 범위를 넘는다. 출시 후 검토.
**되돌리는 비용:** 낮음

## 유행 노선 (Q2) — 되돌리기 비용으로 가른다

**결정:** A/B 배타 선택을 폐기한다. 항목별로 나눈다.

| 항목 | 되돌리기 비용 | 노선 |
|---|---|---|
| 정체성 | 높음 | **B** — ASMR 인크리멘탈. 왁뿌볼은 소재 |
| 제목 (한/영) | 매우 높음 | **B** — 유행어를 제목에 넣지 않는다 |
| 태그 · 짧은 설명 | 0 | **A** — `wax cracking` 계열 검색어를 넣는다 |
| 출시 예정 페이지 | 0 | **A** — 최속 공개 |
| 데모 · 넥스트 페스트 | 회수 불가 | **B** — 2027년 2월 회차 |

**이유:** (2026-08 조사)

1. **일정이 A를 물리적으로 부정한다.** 넥스트 페스트 2026년 10월 회차의
   등록 마감은 8월 31일이고 대기자 명단도 예외도 없다. 참가 요건이
   "이미 공개된 스토어 페이지"인데 오늘 기준 Steamworks 가입도 안 된 상태다.
   다음 회차는 2027년 2월이고, 참가 게임은 회차 종료 후 출시해야 한다.
   → **출시는 2027년 봄.** 2026년 여름 유행에 올라탈 수 있는 경로가 없다.

2. **유행 소비층은 이미 무료로 소비 중이다.** Roblox 에 왁스 부수기 게임이
   다수 (왁뿌타, Wax Squishy Tower, Crunchy Wax Escape), 모바일에
   `Wax Pop Ball: ASMR Squishy`, 웹에 wakbbuball.com.
   유행을 보고 온 사람에게 4,000원을 받으려면 무료판이 못 주는 걸 줘야 한다.
   그건 유행이 아니라 **인크리멘탈의 깊이**다.

3. **정확한 선례가 실패했다.** `Bubble POP IT ASMR` (2021-10 출시, ₩2,250)은
   팝잇 유행 정점 직후에 나온 유행 소재 ASMR 클리커다. **리뷰 6개**로
   점수 산출조차 안 됐다. 얇은 게임에 유행을 얹는 전략의 결과가 이미 있다.

4. **반대로 스팀에는 이 소재가 비어 있다.** 왁스 부수기 소재 게임이 스팀에
   없다. 무료 플랫폼은 포화, 유료 플랫폼은 공백이다. 이 공백은 유행이
   식어도 남는다 — 부서지는 감각은 유행보다 오래 산다.

5. **검색 유입은 태그로 회수된다.** 제목에 유행어를 박는 이득의 대부분은
   태그·짧은 설명·숏폼으로 얻을 수 있고, 그쪽은 언제든 되돌릴 수 있다.

**포기한 것:** 2026년 유행 피크 구간의 판매. 되찾을 수 없다.
대신 유행이 식은 뒤에도 팔리는 게임을 얻는다.

**되돌리는 비용:** 태그·설명은 5분. 제목과 정체성은 사실상 불가.

**부수 확인:**
- `왁뿌볼`은 "왁스 뿌시기 볼"의 줄임말인 **일반명사**다. 특정 브랜드가 아니다.
  → 상표 리스크 낮음. 단 실물 제품 조형을 알아볼 수 있게 재현하는 것은 별개 문제다.
- 영어권 명칭은 **`wax cracking`** 이 표준이다 (`wax cracking squishy`,
  `wax-popping ball` 병용). TikTok 에 전용 트렌드 페이지가 있다.
  영문 스토어 문구는 이 표기를 쓴다.

## 게임 제목 — Clack & Crackle / 나만 없어 왁뿌볼

**결정:** 영문 및 전 언어 `Clack & Crackle`. 한국어만 `나만 없어 왁뿌볼`.

**이유:** `Clack` 은 키캡 타건음, `Crackle` 은 왁스 파열음이다. 두 소재를
하나씩 맡고 둘 다 의성어라 유행어가 0 이다. Q2 의 B 노선을 정확히 지킨다.
`Crackle` 은 `crack` 과 별개 단어라 불법복제 검색 충돌을 피하고, `Clack` 은
기계식 키보드 커뮤니티의 표준 용어라 유행과 무관한 니치 유입이 있다.
스팀에 동명 게임 없음 (2026-08 확인).

한국어만 유행어를 태우는 이유: **영문 주제목이 스토어 URL 과 앱 식별자를
결정하므로 현지화 제목의 변경 비용은 훨씬 낮다.** 되돌리기 비용이 낮은
자리에 유행을 태운다는 Q2 원칙 그대로다. 유행이 죽으면 한국어만 바꾼다.

**포기한 것:** 제목의 장르 신호. 두 제목 다 클리커/인크리멘탈임을 알리지
않는다. **짧은 설명이 그 일을 전부 떠맡아야 한다.**
한국어 캡슐 이미지도 별도 제작해야 한다 (제목이 다르므로).

**되돌리는 비용:** 영문은 사실상 불가 (URL·찜·리뷰가 얽힘). 한국어는 낮음.

## 지원 언어 — 출시 9개 언어 (T1)

**결정:** 출시 시점 한/영/중간체/러시아어/일/스페인/포르투갈(브라질)/독일/프랑스.
출시 후 T2 6개 추가. 아랍어는 T3 로 분리.

**이유:** 스팀 점유율(2026-03) 상위 5개가 전체의 약 80%다.
**러시아어가 9.21% 로 3위**인데 초안 목록에 없었다. 일본어·한국어는
점유율은 낮지만 플레이어당 지출이 평균 이상이라 ROI 가 따로 선다.
클리커는 텍스트가 적어 언어당 한계비용이 낮다 — 총 400~500 키.

힌디어는 스팀 전체 플랫폼 지원 언어 목록에 없다. 인도 사용자는 영어로 쓴다.

**아랍어를 T3 로 내린 이유:** 비용의 급이 다르다. RTL 로 UI 가 좌우 반전되고
(HUD 가 HTML 이라 `dir="rtl"` 로 상당 부분 해결되는 건 이득), 아랍어는
글자가 문맥에 따라 네 형태로 바뀌며 이어지므로 **비트맵 픽셀 폰트로는
사실상 불가능하다.** 시스템 폰트로 폴백하면 그 언어에서만 픽셀아트 톤이
깨진다. 점유율 10위 안에도 없다. 넣지 말자는 게 아니라 T1 이후 별도 작업이다.

**포기한 것:** 아랍어권 초기 노출.

**되돌리는 비용:** 낮음 — 언어 추가는 JSON 1개 + 코드 1줄로 설계했다
(`docs/10-I18N.md`). **그 성질을 깨뜨리지 말 것.**
