# 03 — 아트

## 해상도 규격 (확정)

| 항목 | 값 |
|---|---|
| 논리 해상도 | **640 × 360** |
| 화면 배율 | ×3 → 1920×1080 정확히 일치 |
| 키캡 | **72 × 72** (화면상 216px = 세로 1/5) |
| 왁뿌볼 | 40 × 40 |
| 필드 슬롯 | 48 × 48 |
| 도감 썸네일 | 24 × 24 |
| 필터 | nearest. linear 절대 금지 |
| 좌표 | 정수만 |

**1024×1024 는 픽셀아트 규격이 아니다.** 그 크기로 그려서 216px 로 축소하면
픽셀이 뭉개져 픽셀아트가 아니게 된다. 72×72 로 직접 그릴 것.

코드의 `VIEW_W`/`VIEW_H` 를 640/360 으로 바꿔야 한다 (현재 480/270).

## 왁뿌볼 — 250개를 그리지 않는 법

종류 50 × 등급 5 = 250조합인데, 실제 제작물은 **60장**이다.

| 요소 | 담당 | 제작물 |
|---|---|---|
| 종류 | 모양 | 스프라이트 **50** |
| 등급 | 색 + 이펙트 | 틴트/필터 **5** |
| 균열 | 파괴 단계 | **공용 오버레이 5** |

**균열을 종류별로 그리지 말 것.** 왁스 껍질이 깨지는 표현이라
반투명 오버레이 5장을 종류 위에 얹으면 된다. 소재상으로도 자연스럽다.
종류별로 그리면 250프레임이 된다.

| 등급 | 표현 |
|---|---|
| Common | 원본 색 |
| Rare | 초록 틴트 + 얇은 테두리 |
| Epic | 보라 틴트 + 발광 테두리 |
| Legendary | 금 틴트 + 발광 + 반짝 파티클 |
| Supreme | 프리즘(색상 회전) + 상시 파티클 |

Supreme 표현 방식은 미결 (`01-OPEN-QUESTIONS.md` Q4).

**★ 희귀도는 왁뿌볼 자체에 표시하지 않는다.** 도감에서만 별로 보여준다.
화면의 왁뿌볼은 등급 색만 입는다. 두 축이 화면에서 겹치면 혼란스럽다.

## 팔레트

`src/render/palette.ts` 와 `index.html` CSS 변수 두 곳. **항상 같이 고칠 것.**

```
--case   #14161c   케이스 (배경)
--plate  #272d3a   플레이트
--cap    #e8e2d4   키캡 상단 (PBT 베이지)
--amber  #f2b705   골드 / 강조
--jade   #6ec3c1   보조
```

배경을 어둡게 유지하는 이유: 왁뿌볼이 부서질 때 파편과 빛이 튀어야 하는데
밝은 배경에서는 안 보인다. 흰색 Common 도 어두운 배경이라 충분히 보인다.

**왁뿌볼 50종은 이 팔레트에 매이지 않는다.** 알록달록해야 소재에 맞다.
다만 배경/UI 와 충돌하지 않게 채도 상한은 둘 것.

## 에셋 파이프라인 (AssetPack)

에셋이 90장을 넘는다. 개별 PNG 로 로드하면 요청 90번에 Pixi 배칭도 못 쓴다.

```
assets/          ← raw PNG 를 여기에
  balls/
  keycaps/
  cracks/
  ui/
  fx/
        │  npm run assets
        ▼
public/atlas/    ← 스프라이트시트 + json
```

런타임 코드는 아틀라스에서 **프레임 이름**으로 꺼내 쓴다.
`core/content/` 의 `spriteKey` 가 그 프레임 이름과 일치해야 한다.

PNG 를 추가하거나 고친 뒤에는 반드시 `npm run assets` 를 다시 돌릴 것.

## 작업 규칙

- 안티에일리어싱 금지
- 논리 해상도 기준으로 직접 그린다. 크게 그려서 축소 금지
- 파일명: `cap_NNN.png`, `ball_NNN.png`, `crack_N.png`, `fx_*.png`, `ui_*.png`
  `core/content/` 의 키와 정확히 일치할 것
- **왁뿌볼 50종은 실루엣이 서로 구분되어야 한다.** 40×40 에서 색만 다르면
  도감에서 구별이 안 된다

도구: Aseprite / LibreSprite / Piskel
