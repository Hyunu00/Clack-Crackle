# 04 — 사운드

**이 게임에서 가장 중요한 문서다.**

플레이어가 사는 것은 왁뿌볼이 부서지는 소리다. 숫자는 그 소리를 언제
들려줄지 조절하는 장치일 뿐이다. 밸런스가 별로면 지루한 게임이지만,
사운드가 별로면 아무것도 아닌 게임이 된다.

**음원 조달은 직접 하기로 확정.** 이 문서는 필요 목록과 구현 규칙만 정의한다.

---

## ⚠️ 50종 × 5등급 사운드를 다 녹음하지 말 것

아트와 같은 직교 구조를 쓴다.

| 요소 | 제작물 |
|---|---|
| 종류별 파괴음 | 50종 × 3~5변주 |
| 등급 스팅 (위에 겹침) | 5개 |

250세트가 아니라 **50세트 + 5스팅**이다.

50종 녹음도 부담이면 **희귀도 그룹 단위로 묶어도 된다.**
★1 18종이 같은 계열 소리를 쓰고 종류별로 피치만 다르게 하는 식.
플레이어는 ★5 소리가 특별하다는 것만 알면 된다.

## 사운드 목록

### 코어

| 키 | 설명 | 변주 |
|---|---|---|
| `cap_press` | 키캡 타건 | 4~6 |
| `ball_crack_<단계>` | 균열 **1~5단계** (공용) | 단계당 3 |
| `ball_shatter_<종류>` | 완전 파괴 | 종류당 3~5 |
| `ball_spawn` | 왁뿌볼이 필드에 나옴 | 2 |
| `coin` | 골드 획득 | 3 |

**균열은 5단계다** (🟢 2026-08 확정). 진행률 20% 간격으로 한 단계씩 넘어가고,
넘어가는 순간마다 `ball_crack_N` 이 나간다. 100% 에서 `ball_shatter_<종류>`.
단계 정의와 진행률 계산은 `docs/02-ECONOMY.md` 의 "균열 5단계" 가 원본이다.
아트 오버레이도 같은 5장이다 (`docs/03-ART.md`).

### 등급 스팅 (파괴음 위에 겹침)

`sting_rare` / `sting_epic` / `sting_legendary` / `sting_supreme`

**Supreme 스팅에 예산을 쓸 것.** 클립으로 퍼지는 건 이 순간이다.

### 룰렛 / 시스템

| 키 | 설명 |
|---|---|
| `roulette_roll` | 슬롯 회전 |
| `roulette_result_<등급>` | 결과 공개 |
| `roulette_fail` | 꽝 |
| `type_unlock` | **종류 신규 해금.** 50번 들을 소리 |
| `type_levelup` | 종류 레벨업 (해금보다 가볍게) |
| `frag_get` | 조각 획득 |
| `cap_complete` | 키캡 완성 |
| `dex_new` | 도감 신규 등록 |
| `rebirth` | 환생 |
| `skill_buy` | 스킬 노드 구매 |
| `ui_denied` | 골드 부족 |
| `field_full` | 보관함 확대 화면 열림 |

### 앰비언스

`amb_room` — 조용한 방 톤. 아주 작게.

**키캡별 타건음:** 24종 각각 다르게 할지, 등급별 5종만 쓸지는 음원 확보
상황에 맞춰 결정. 코드는 `keycap.soundKey` 로 참조하므로 어느 쪽이든 대응된다.

## 구현 규칙

**사운드 정의는 데이터다.** `src/core/content/audio.ts` 에 목록으로만 두고,
재생 코드가 파일명을 직접 알지 못하게 한다.

`src/audio/` 는 `GameEvent` 를 구독해서 재생한다. `core` 는 오디오를 모른다.

### 필수 처리

1. **랜덤 변주** — 직전에 쓴 인덱스를 피한다
2. **피치 변주** — 재생마다 ±5%. 이것만으로 반복감이 크게 준다
3. **동시 재생 상한** — 자동 파괴가 켜지면 소리가 폭발한다.
   같은 키는 짧은 시간 내 N개까지. 넘으면 무시하거나 볼륨 감쇠
4. **꾹 누르기 전용 사운드** — 개별 타건음 반복이 아니라 **연속 균열음**이다.
   누르고 있는 동안 진행률이 계속 오르고, 단계가 넘어갈 때마다
   `ball_crack_1` → `…5` 가 이어져 **하나의 끊기지 않는 파열음**으로 들려야 한다.
   30타가 5회 소리로 압축되는 셈이다. 자세한 건 아래 "균열 5단계" 참조
5. **자동 파괴 볼륨 차등** — 수동보다 조용하게.
   자동이 켜지면 게임의 대부분이 자동으로 깨지므로 여기가 시끄러우면 고문이다
6. **볼륨 슬라이더** — 마스터/효과음/BGM 분리. ASMR 게임에서 필수
7. **포맷** — `.ogg` 우선, `.m4a` 폴백. `.wav` 는 배포에 쓰지 말 것

라이브러리: **howler.js 2.2.4** (`npm i howler` + `npm i -D @types/howler`)

`src/core/content/audio.ts` 는 데이터만 두고, `src/audio/` 가 howler 를 감싼다.
`core` 는 howler 를 import 하지 않는다.

### 음원이 없을 때

`public/sfx/` 에 파일이 없으면 조용히 넘어가고 콘솔에 **비어 있는 키 목록**을
찍는다. 그게 녹음 체크리스트가 된다.

## BGM

ASMR 게임에서 BGM 은 방해가 될 수 있다.
**기본 꺼짐, 설정에서 켤 수 있게.**

무료 음원을 쓴다면 라이선스 확인 필수.
"무료"와 "상업 이용 가능"은 다르다.

## 접근성

청각 의존 게임이므로 대체 경로가 필요하다.

- 균열/파괴는 시각적으로도 명확히
- 등급은 소리 없이도 구분 가능해야 함
- "중요 사운드 시 화면 플래시" 옵션 고려
