## 확정된 것

🟢 왁뿌볼 종류 **50종 목표**, ★1~★5 희귀도
🟢 종류는 룰렛으로 해금. 시작은 ★1 중 1종만
🟢 중복 해금 = **종류 레벨업** (상한 없음, 룰렛 전용, 골드 직접 구매 불가)
🟢 해금은 희귀도 추첨 / 레벨업은 **균등 랜덤** (희귀도 무관)
🟢 신규 해금 우선 없음. 전부 랜덤
🟢 도감은 **종류 단위 50칸** + 칸당 등급 점
🟢 자동화 **3단계 전부** 도입 (자동 키캡 / 자동 파괴 / 자동 룰렛)
🟢 **자동 파괴는 등급별 스킬트리 해금** (2026-09, Q1 해결) — 노드 레벨 1~5 가
   Common→Supreme 순으로 열린다. 골드 60%. 해금해도 전체 ON/OFF 토글은 그대로.
   **자동으로 깨져도 소리는 반드시 난다.** 전문은 `docs/06-DECISIONS.md`
🟢 **연타 없음** (2026-09) — 왁뿌볼은 **꾹 누르기 하나로만** 부순다.
   수동 100% / 자동 60%. 키캡 클릭은 별개이고 그대로 유지된다
🟢 **파괴 1회 = 약 3초** (2026-09) — 균열 단계와 파괴음이 들어가는 그릇이다.
   꾹 누르기는 초당 약 33%. 밸런스 수치가 아니라 **감각 제약**이라
   다른 수치가 여기에 맞춘다
🟢 **끊어 누르기** (2026-09) — 꾹 누르다 떼도 진행률이 유지된다.
   다시 누르면 이어서 진행되고 소리가 새로 난다. 한 번에 꾹 눌러 끝내도 되고
   짧게 끊어 눌러도 된다. **어느 쪽이든 골드 100%**
🟡 **균열 단계 기본 4, 설정으로 3~5** (2026-09) — 오버레이·사운드는 5종을
   그대로 제작하고 그중 N개를 균등하게 쓴다. 마지막은 항상 5번.
   **감각 설정이라 파괴 시간·골드는 변하지 않는다**
🟢 보관함 꽉 참 → 확대 화면에서 **교체 또는 즉시 파괴** 선택.
   **"항상 이렇게" 옵션 제공**, 자동 파괴 해금 등급은 화면 없이 자동 처리
🟢 환생재화 = **√(누적 골드) 스케일**
🟢 **2차 환생 여지** — 구현 안 하되 세이브를 3층으로 구성
🟢 **균열 오버레이·사운드 5종 제작** (2026-08) — 공용 5장 + `ball_crack_1`~`5`.
   **진행률로** 계산한다 (시간·클릭 아님). 실제 재생 단계 수는 위의
   "기본 4, 설정 3~5" 항목 참조. 전문은 `docs/02-ECONOMY.md`
