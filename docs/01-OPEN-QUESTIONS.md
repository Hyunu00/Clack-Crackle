## B. 확정 대기

**Q1 🟡 자동 파괴 판정 단위** — 조합 단위(종류×등급)로 제안했다.
종류 단위면 "사과를 한 번 깼으면 사과 Supreme 도 자동"이 되어
가장 보고 싶은 순간을 놓친다. 확정 필요.

**Q3 🟡 화면 레이아웃** — 프로토타입 보면서 결정하기로 함.
논점: 키캡과 필드 사이를 마우스가 왕복한다. 수천 번 반복할 동선이라
**가깝게 붙이는 쪽**을 권함.

**Q4 🔴 프리즘(Supreme) 표현** — 셰이더 색상 회전? 팔레트 사이클?
캐주얼 아트 톤을 지키면서 화려해야 한다.

**Q5 🔴 보관함 확대 화면의 조작** — 새로 얻은 것 + 필드 5개를 나란히 보여주고
교체/즉시파괴를 고르게 한다는 것까지는 정해짐. 클릭 몇 번에 끝나는지,
"항상 이렇게" 옵션을 줄지는 미정. **자주 뜨는 화면이라 마찰이 크면 안 된다.**

## 확정된 것

🟢 왁뿌볼 종류 **50종 목표**, ★1~★5 희귀도
🟢 종류는 룰렛으로 해금. 시작은 ★1 중 1종만
🟢 중복 해금 = **종류 레벨업** (상한 없음, 룰렛 전용, 골드 직접 구매 불가)
🟢 해금은 희귀도 추첨 / 레벨업은 **균등 랜덤** (희귀도 무관)
🟢 신규 해금 우선 없음. 전부 랜덤
🟢 도감은 **종류 단위 50칸** + 칸당 등급 점
🟢 자동화 **3단계 전부** 도입 (자동 키캡 / 자동 파괴 / 자동 룰렛)
🟢 자동 파괴는 **전체 ON/OFF**, 골드 60%
🟢 보관함 꽉 참 → 확대 화면에서 **교체 또는 즉시 파괴** 선택
🟢 환생재화 = **√(누적 골드) 스케일**
🟢 **2차 환생 여지** — 구현 안 하되 세이브를 3층으로 구성

   진행률 20% 간격이고 **클릭 수가 아니라 진행률로** 계산한다.
