# 00 — 컨셉

## 한 줄

키캡을 눌러 왁뿌볼을 뽑아내고, 부수고, 모으는 캐주얼 아트 ASMR 인크리멘탈.

## 소재가 왜 잘 맞는가

현실 왁뿌볼의 소비 루프:

```
산다 → 누른다 → 왁스가 바삭 깨진다 → 촉감/소리 쾌감 → 복구 불가 → 또 산다
```

인크리멘탈 루프와 구조가 같다. 특히 **복구 불가**가 감정의 핵심이다.
한 번 부수면 끝이라 아깝고, 그래서 다음 걸 원한다.

그래서 **필드 5칸이 전부이고 창고가 없다.**
"재고 관리" 같은 표현은 감정을 죽인다.

## 핵심 루프

```
키캡 클릭 ──▶ 골드(소량)
     │
     └──(N타마다)──▶ 왁뿌볼 ──▶ 필드(5칸)
                                   │
                        꾹 누르기 / 자동
                                   │
                     ┌─────────────┴──────────────┐
                 골드(주 수입)              환생재화(적립)
                     │                            │
                   룰렛                          환생
                     │                            │
    키캡조각 / 왁뿌볼 / 종류해금·레벨업 / 꽝    스킬트리
```

**키캡은 무료 공급원, 룰렛은 유료 업그레이드 경로.**
골드가 0이어도 키캡만 두들기면 게임이 돌아간다. 초반 진입이 막히지 않는다.

## 4층 구조

| 층 | 무엇 | 시간 스케일 | 목적 |
|---|---|---|---|
| 감각층 | 누르기 / 부서짐 / 파괴음 | 0.1초 | 손맛. 정체성 |
| 진행층 | 골드 / 룰렛 / 환생 / 스킬트리 | 분~시간 | 세션 유지 |
| 수집층 | 왁뿌볼 도감 50 + 키캡 24 | 시간~일 | 장기 목표 |
| 무한층 | 종류 레벨업 / 무한 노드 / 도감 점 | 수십 시간 | 엔딩 없는 게임의 바닥 |

**수집층이 메인이다.** 게임의 이름이 왁뿌볼이고, 부수는 게 본체고,
종류를 50개 만들 거라면 진짜 목표는 왁뿌볼 도감이다.
키캡 컬렉션은 그걸 돕는 도구 축이다.

## 엔딩

**없다.** 도감 50칸도, 키캡 24종도 마일스톤이지 종료 조건이 아니다.

완성 후에 남는 것:
- 도감 점 250개 (종류 × 등급 조합)
- 종류 레벨업 (상한 없음)
- 스킬트리 무한 노드
- 누적 통계, 업적
- 업데이트로 추가되는 종류

출시 후 확장은 **왁뿌볼 종류 추가**가 가장 싸다.
스프라이트 1개 + 기초 가치 1개 = 5조합 추가.

## 톤

기계식 키보드의 물성 + 문구점 왁뿌볼의 유치한 즐거움.
과하게 세련되면 소재를 배신하고, 과하게 유치하면 스팀에서 안 팔린다.

## 시장 리스크 (Q2 확정, 2026-08)

왁뿌볼 유행은 2025년 말 해외 숏폼에서 시작해 **2026년 여름에 정점**을 찍었다.
7월 중순부터 회고·비판 기사가 나오기 시작했다 — 유행 곡선 후반부 신호다.

**유행에 올라타는 경로는 이미 닫혔다.** 넥스트 페스트 2026년 10월 회차의
등록 마감이 8월 31일이고 예외가 없다. 다음 회차는 2027년 2월이며 참가작은
회차 종료 후에 출시해야 한다. → **출시는 2027년 봄.**

그래서 A/B 배타 선택을 폐기하고 **되돌리기 비용으로 갈랐다.**

| 항목 | 노선 |
|---|---|
| 정체성 · 제목 | **B** — ASMR 인크리멘탈. 왁뿌볼은 소재이지 주어가 아니다 |
| 태그 · 짧은 설명 · 숏폼 | **A** — `wax cracking` 계열 검색어를 싣는다 |
| 출시 예정 페이지 | **A** — 최속 공개 |
| 데모 · 넥스트 페스트 | **B** — 2027년 2월. 게임당 평생 1회다 |

근거 전문은 `docs/06-DECISIONS.md` 의 "유행 노선 (Q2)".

### 경쟁 지형

| 플랫폼 | 상태 |
|---|---|
| Roblox / 모바일 / 웹 | **포화.** 왁스 부수기 게임이 이미 여럿, 전부 무료 |
| 스팀 | **공백.** 이 소재의 게임이 없다 |

유행을 보고 온 사람에게 4,000원을 받으려면 무료판이 못 주는 걸 줘야 하고,
그건 유행이 아니라 **인크리멘탈의 깊이**다. 도감 50칸, 환생, 스킬트리가
그 답이다. 무료 왁스깨기 게임은 여기까지 오지 않는다.

## 상업적 리스크

**데모 없는 4,000원 클리커**가 현재 기획의 가장 큰 위험이다.
무료 웹 클리커가 널린 시장이라 유료는 진입장벽이 높고, ASMR 은
"들어봐야 아는" 가치라 스크린샷과 글로는 설득이 안 된다.

데모 + 스팀 넥스트 페스트가 사실상 유일한 해법이다. → **2027년 2월 회차 확정.**

**선례:** `Bubble POP IT ASMR` (2021-10, ₩2,250)은 팝잇 유행 정점 직후에 나온
유행 소재 ASMR 클리커다. 리뷰 6개로 점수 산출조차 안 됐다.
얇은 게임에 유행을 얹는 전략의 결과가 이미 나와 있다.
이 기획이 그것과 갈리는 지점은 **깊이 하나뿐이다.**
